# KPSS Kokpit

Kendi PDF kaynaklarından beslenen, yapay zekâ destekli KPSS çalışma uygulaması.

**Uygulama:** https://esm3r.github.io/kpss-kokpit/

Bu depo yalnızca derlenmiş uygulamayı içerir; kaynak kod ayrı, gizli bir depoda. Kitapların, notların, kartların ve API anahtarın bu sitede değil, kendi cihazında (tarayıcının IndexedDB'sinde) durur.

Tablete kurmak: Chrome'da adresi aç → menü (⋮) → **Uygulamayı yükle** / **Ana ekrana ekle**. Samsung Internet'te: menü (≡) → **Sayfayı ekle** → **Ana ekran**.
